Methodology

10 generic coding prompts evaluated via Claude MiniMax M2.7 API. Each prompt run in three modes:

  • Baseline Standard prompting without compression
  • caveman-full Ultra-compressed caveman communication style
  • caveman-translate Wenyan mode with EN↔ZH translation layer

Prompts used: string reversal, file I/O, JS variables, CSS flexbox, array merge, React useEffect, palindrome, PostgreSQL, REST APIs, bash scripting.
